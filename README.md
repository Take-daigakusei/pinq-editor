# 🏓 サークル誌「ぴん球」編集・発行ツール

サークル誌「ぴん球」の制作（PDF結合・用紙サイズ統一・黒塗り校正・編集後記の作成）を、**インストール不要・ブラウザを開くだけで誰でも簡単に行える専用ツール** です。

外部のWebサイト（iLovePDF や PDF24 Tools）を使う必要がなく、**すべてパソコン内（ローカル）で瞬時に処理** されます。

---

## 💻 総務の方向け：使い方（たったの4ステップ）

特別なソフトやPythonなどのダウンロードは一切不要です！

### ステップ1：ツールを開く
フォルダ内の **`ぴん球エディタ.html`** （または `エディタを開く.bat`）をダブルクリックします。  
普段お使いのブラウザ（Google Chrome や Microsoft Edge 等）で編集画面が開きます。

### ステップ2：PDFを配置する
画面左側の各エリアに、LINE等で集めたPDFを配置します：
1. **表紙**: 表紙PDFをドラッグ＆ドロップ（またはファイル選択）
2. **本文**: 本文PDFをまとめてドラッグ＆ドロップ（「▲」「▼」で並び順を変更できます）
3. **編集後記**: 必要な場合は文章・日付・掲載画像を入力（不要ならチェックを外すだけ）
4. **裏表紙**: 裏表紙PDFをドラッグ＆ドロップ

### ステップ3：黒塗り校正（必要な場合）
右側のプレビュー画面でページを確認しながら、隠したい個人情報や連絡先を **マウスでドラッグして囲むだけ** で黒塗り（墨消し）できます。

### ステップ4：完成版PDFをダウンロード
左下の緑色のボタン **「🚀 完成版PDFを発行してダウンロード」** をクリックします。  
全ページが自動で綺麗なA4サイズに統一され、黒塗りと編集後記が反映された完成版PDF（`ぴん球_完成版_YYYYMMDD.pdf`）がパソコンのダウンロードフォルダに保存されます！

---

## 🌟 主な便利機能
- **追加インストール一切不要**: パソコンに最初から入っているブラウザだけで動きます。
- **用紙サイズの自動統一**: 各人から送られてくるPDFのサイズや縦横がバラバラでも、自動的にきれいなA4縦の中央に縮尺を合わせて整列します。
  - 日程表など**横長の表**を、横のまま載せたいときは、「5. 統一用紙サイズ」で **「A4（元の縦横のまま・縦横が混ざる）」** を選びます。横長のPDFページだけがA4横になり、ほかはA4縦です（編集後記・画像はA4縦）。
- **安心のプライバシー保護**: ネット上の外部サーバーには一切ファイルを送信しません。自分のパソコン内だけで処理が完結します。
- **オフライン動作**: ネットがつながらない場所でも使用可能です。
- **目次**: 表紙の次のページに、いつも「目次」が入ります。はじめから「巻頭言　　野部」と「まるれんのこーなー　　練習係」が入っていて、その下に書き足した行が、そのまま載ります。空の行は空きになります。行が多いときは、自動で文字を小さくして1ページに収めます。
- **並び替え**: 本文の一覧は、「⠿」をつかんでドラッグすると並び替えできます（スマホは指で）。「名前順」「逆順」のボタンもあります。並び替えても、黒塗りは同じページについてきます。
- **🧰 ツール**（右上のボタン）:
  - **分割（切り出し）**: 編集中のPDF、またはアーカイブのPDFから、切り出したいページをタップで選びます。編集中の本文から切り出すと、その場で本文が分かれ、切り出したページは独立した本文として並び替え・黒塗りができます（黒塗りもついてきます）。それ以外から切り出すと、選んだページが新しい本文として最後に追加されます。
  - **圧縮**: **文字はそのまま**（拡大してもきれいで、選択・検索もできます）、PDFの中の写真・画像だけを軽くします。画像のないPDF（文字だけ）は、ほとんど小さくなりません。それでも小さくしたいときだけ、「強力モード」（ページ全体を画像にする。文字が少しぼやけます）を使います。
  - **アーカイブ**: 完成版を発行すると、自動で、この端末のブラウザ内に残ります。一覧から、保存・共有・開く・圧縮・名前の変更・削除ができます。過去のPDFを追加することもできます（ブラウザの閲覧データを消すと、アーカイブも消えます）。
- **執筆依頼の管理**: 右上の「✍️ 執筆依頼」から、別のページ（https://circle-roster.web.app/pinq-writers.html）が開きます。誰に表紙・裏表紙・本文を頼むか、返事待ちや断られた人、号ごとの一覧を、総務のメンバーで共有して管理できます（ログインが要ります）。**このツールのPDF処理は、これまでどおり、ネットに送らず、パソコン内だけで動きます。**
